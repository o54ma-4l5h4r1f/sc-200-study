## Azure first

- A **threat indicator** (also *indicator of compromise*, **IoC**) is a known-bad artefact: an IP address, domain, URL, file hash, email address. Sentinel compares your logs against them.
- An **app registration** is an identity for a program in **Microsoft Entra ID**. A threat-intelligence platform uses one (application ID + client secret) to sign in and push indicators.
- The **Microsoft Sentinel Contributor** role is an Azure RBAC role on the workspace. It's what lets that app — or you — write threat intelligence.
- Indicators are stored as rows in workspace **tables** like any other log, so KQL and analytics rules can use them.

New to these? Read the Foundations pages linked above.

## In one sentence

You get threat indicators into Sentinel through the **Threat Intelligence** solution's connectors — **Microsoft Defender Threat Intelligence**, **Threat Intelligence – TAXII**, the **upload API** (no connector needed), or by creating them by hand — and they land in the **`ThreatIntelIndicators`** and **`ThreatIntelObjects`** tables.

## Why it exists

A hotel front desk keeps a list of banned guests sent by the police and by other hotels. Each new guest is checked against it. Threat intelligence is that list; analytics rules do the checking. This bullet is about **filling the list**: which feeds, which pipe, which table.

## What actually matters

**1. STIX vs TAXII.** **STIX** is the *format* — a standard way to write threat intelligence as objects (indicator, threat actor, attack pattern, identity, relationship). **TAXII** is the *transport* — the protocol servers use to share STIX. Exam distractors swap them.

**2. The ingestion options.**

| Option | Direction | What you configure | Watch out |
|---|---|---|---|
| **Microsoft Defender Threat Intelligence** (standard / premium) | Microsoft → Sentinel | Click **Connect** | The standalone MDTI SKU reached end of life **1 August 2026**; its capabilities are now included for Defender and Sentinel customers. Premium connector docs still mention the old "MDTI API Access SKU". |
| **Threat Intelligence – TAXII** | Sentinel **pulls** from a TAXII 2.0 / 2.1 server | **Friendly name**, **API root URL**, **Collection ID**, username/password if needed, polling frequency | Some servers (FS-ISAC) need Sentinel's client IPs allow-listed |
| **Upload API** (preview) | Your TIP **pushes** STIX objects | Entra **app registration** + client secret; app gets **Microsoft Sentinel Contributor** on the **workspace**; you give the TIP the app ID, an OAuth 2.0 token and the **workspace ID** | ==@No data connector needed== — the training unit lists it with the connectors (it ships in the Threat Intelligence solution), but the API itself needs no connector enabled |
| **Threat Intelligence Platforms** (TIP) | TIP pushes via Microsoft Graph `tiIndicators` | App with `ThreatIndicators.ReadWrite.OwnedBy`, admin consent, target product "Azure Sentinel" | ==!Deprecated — stopped collecting in June 2026.== Use the upload API |
| **TAXII Export** | Sentinel **pushes** to a TAXII 2.1 server | API root, collection ID, Basic auth or API key | Export, not ingestion |
| **Manual** | You create objects | Add new > TI object | Needs Microsoft Sentinel Contributor |

All connectors come in the **Threat Intelligence** solution in Content hub. Installing it needs **Microsoft Sentinel Contributor at resource-group level**. Configuring a connector needs read/write on the workspace. Registering the app needs an Entra role such as **Application Administrator**, **Application Developer** or **Cloud Application Administrator** if users can't register apps by default.

**3. Tables — and a training contradiction.** Since **3 April 2025** Sentinel writes to **`ThreatIntelIndicators`** (indicators) and **`ThreatIntelObjects`** (other STIX objects). It ==!stopped writing the legacy `ThreatIntelligenceIndicator` table after 31 July 2025==. The training modules and the connector reference still say `ThreatIntelligenceIndicator`. The product docs are newer: use the new tables. Sentinel re-ingests all TI every 7–10 days and keeps the newest version of each object (by `Id`).

**4. Ingestion rules.** Filter or modify objects from **connectors** before they're stored — e.g. drop old, low-confidence indicators or extend "Valid until" by 30 days. They don't touch upload-API or manual objects. Rules run in order until a Delete; changes take up to **15 minutes**.

**5. Curating.** **Tags** (free-form), **relationships** (indicator *attributed to* threat actor), and **TLP** sensitivity: White, Green, Amber, Red. The built-in **Threat Intelligence workbook** visualises it.

| Task | Defender portal | Azure portal |
|---|---|---|
| Install solution | **Microsoft Sentinel > Content management > Content hub** > **Threat Intelligence** | **Content management > Content hub** |
| Connectors | **Microsoft Sentinel > Configuration > Data connectors** | **Configuration > Data connectors** |
| View / create / tag | **Threat intelligence > Intel explorer** (the training module and the Sentinel-in-Defender quick-reference table still say **Intel management** — same page, renamed; the newest TI articles say Intel explorer) | **Microsoft Sentinel > Threat management > Threat intelligence** |
| Query | **Advanced hunting** | **Logs** |

Which portal: after **31 March 2027** Sentinel is no longer supported in the Azure portal and lives only in the Defender portal. Learn the Defender path first.

The legacy TIP connector shows in the gallery as **Threat Intelligence Platforms - BEING DEPRECATED**.

App role for the upload API: **Azure portal > Log Analytics workspaces > (workspace) > Access control (IAM) > Add role assignment > Microsoft Sentinel Contributor > User, group, or service principal** — search for the app by name; apps aren't listed by default.

| where TimeGenerated > ago(7d)
| summarize count() by SourceSystem

## Exam traps

- "Bring indicators from a TAXII 2.1 server." ==+Threat Intelligence – TAXII connector== with API root URL + collection ID. ==!Not the upload API.==
- "Custom TIP sends STIX objects; least admin work." ==+Upload API==, app registration with ==+Microsoft Sentinel Contributor on the workspace==. ==!No connector to enable.==
- "Grant the TIP app `ThreatIndicators.ReadWrite.OwnedBy`." That's the ==!deprecated TIP connector==.
- "Query `ThreatIntelligenceIndicator`." ==!Legacy — no new data since 31 July 2025.== Use `ThreatIntelIndicators` / `ThreatIntelObjects`.
- "Ingestion rules filter upload-API data." ==!No== — connector sources only.
- "STIX is the transport protocol." ==!No== — TAXII is transport, STIX is format.
- "Reader can create indicators." ==!No== — Microsoft Sentinel Contributor or higher.
